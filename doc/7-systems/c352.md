# Namco C352

Furnace's C352 implementation provides 32 PCM voices, independent panning and a 16 MiB sample ROM. samples use signed 8-bit PCM or C219 compressed PCM. other source depths are converted to 8-bit PCM when rendered.

the default clock is 25401600 Hz, with a fixed divider of 288 (88200 samples per second). a custom clock changes the sample rate to clock / 288.

## instruments and samples

use the [C352 instrument editor](../4-instrument/c352.md), or the generic Sample instrument.

- each sample must fit entirely in a 64 KiB bank. Furnace automatically pads to the next bank when necessary.
- a non-looping sample may contain at most 65535 bytes, followed by one silent guard byte.
- a looping sample may contain at most 65536 bytes. the entire sample, including data after the loop end, must fit the bank.
- forward and ping-pong loops are supported. backward loops are rejected. loop end is exclusive in the editor; loop start must precede it and loop end must not exceed sample length.
- a one-sample ping-pong loop behaves as a forward loop. empty samples and invalid loops are rejected.
- the ROM limit includes bank padding and guard bytes. samples which cannot fit are not loaded; check Sample ROM usage in the sample editor.

## chip configuration

**Four outputs (front L/R, rear L/R)** enables four separate outputs in that order. the default stereo mode averages front and rear for each side: L=(FL+RL)/2, R=(FR+RR)/2. use the patchbay to route four-output audio. panning macros control the front and rear pair on each side.

**Custom clock rate** overrides the default clock. both settings are retained in `.fur` songs.

## limitations

VGM export is not supported. hardware LINK, FM, FILTER and undocumented control behavior are not exposed as instrument or chip settings. the debugger provides the common channel state and the 16-bit register sheet.

the `.fur` system ID is `0xe8`; supported rendered sample depths are 8-bit PCM and C219 PCM.
